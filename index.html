CONFIG
設定

    

      

        
◢ YouTube Data API v3PRESET+RSS

        
APIキーがあると、最新/過去動画・再生数・尺を直接取得し、62秒以下をShortsに自動分類します。起動時に前回同期から3時間以上経っていれば自動で同期します。キーはこの端末のブラウザにのみ保存されます。

        

      

      

        ◢ BULK — チャンネル一括登録 / 書き出し
        
チャンネル一覧をテキストで貼り付けてまとめて登録できます。別の端末に移すときは「書き出し」でコピーしたテキストを、移行先で貼り付けてください。

        

      

      

        ◢ ADD HUB — チャンネル追加
        
チャンネルURL、@ハンドル、または UC... のIDを貼り付け。@ハンドル/URLからの自動解決にはAPIキーが必要です。

        

          
          
          
          
        

      

      

        ◢ GENRES — ジャンル
        
ジャンルは自由に作れます。名前・色を変えたり、各チャンネルのジャンルを下の「LINKED HUBS」で切り替えたりできます。「自動でジャンル分け」は動画タイトルの傾向（APIキーがあればYouTubeのカテゴリも）から推定します。

        

        

        

        

      

      

        ◢ LATEST — 最新の基準
        
「最新」タブの期間
この日数以内に公開された動画だけを「最新」タブに表示します

        
NEWバッジの期間
公開からこの日数以内で未視聴の動画に「NEW」を付けます

        
前回の訪問以降もNEWにする
期間外でも、前回アプリを開いた後に公開された動画にNEWを付けます

      

      

        ◢ DISPLAY — 表示
        
レンズ強度
カーソル/指の周りのノードを拡大し、周囲を押し退ける強さ

        
省電力モード
ON：描画を30fps・低解像度にし、ぼかし等の重い効果を止めます。しばらく操作がないとさらに減速。再生中・MATRIX表示中は球体の計算を完全停止します（これは常に有効）。AUTO＝スマホ/タブレットでON

        
効果音
ノードの移動・選択・ダイブ・MAGI審議などに電子音を付けます（再生中は自動で無音）

        
球体を回すときの音
電子音：小さな「ピッ」というデータ音がまばらに鳴る ／ 風：低くやわらかい風の音 ／ なし

        
ダイブ演出
情報欄の「▶ 再生」で、動画の記憶へ潜り込むトランジションを表示します

        
iPhone/iPadの自動再生
無音で自動再生：ダイブ後すぐ再生が始まり、「🔊 タップで音声ON」で音を出します ／ 再生ボタンを押す：音声ありで始めたい場合（毎回 ▶ をタップ）

        
ダイブ後は全画面で再生
ダイブ演出のあと、動画を全画面で再生します（iPhoneはブラウザの仕様で画面いっぱい表示。横向きにすると大きく見られます）

        
字幕
OFF：再生開始時に字幕を自動で消します ／ ON：日本語字幕を表示 ／ YouTube任せ：アカウントや端末の設定に従います

        
パララックス
マウス位置に合わせて球体がわずかに傾く

        
ラベル表示
AUTO: 手前と注目ノードだけ / ALL: すべて / OFF: ホバー時のみ

        
1画面のノード数
多いほど一覧性UP・少ないほど見やすい

      

      

        ◢ DATA — バックアップ
        
ストック・視聴履歴・続きから再生の位置・登録チャンネル・表示設定をJSONで書き出し/読み込みできます（APIキーは含みません）。機種変更や別端末への移行に。

LINK SETUP
チャンネル一括登録

    

      
見たいチャンネルを1行に1つずつ貼り付けてください。登録内容はこの端末のブラウザ内だけに保存され、公開サイトには含まれません。

      
書式：チャンネルID(UC…) または URL / @ハンドル, @ハンドル, 表示名, ジャンル, 色
ジャンルは自由な名前でOK（例：アイドル / ゲーム / 音楽 / お笑い）。空欄なら自動で推定します。2項目目以降は省略可、# で始まる行は無視されます。

      
      

        
        
        
      

      

        
        
APIキーなし：各チャンネルの最新動画をRSSで取得（再生数・尺は取得不可）。APIキーあり：再生数・尺・Shorts判定まで取得。URLや@ハンドルだけの行はAPIキーが必要です。

      

      

      

    

  







  

    
MANUAL
操作ガイド

    

      

        /検索窓を開いて入力（Escでたたむ）
        ← →前/次のクラスター（ページ）
        Space捕捉中の動画を再生
        N Pプレイヤーで次/前の動画
        Sストック切替
        F再生中：全画面 ⇔ 通常表示
        W視聴済み切替
        GNERVE / MATRIX 切替
        Lラベル表示切替
        1〜7タブ切替
        ZShorts表示切替（動画 → ＋Shorts → Shortsのみ）
        MMAGI 審議（おすすめ動画を3人格の多数決で選ぶ）
        Esc閉じる
      

      
スマホ/タブレット：指を置いた場所の周りが拡大し、ノードが押し退けられます。1本指ドラッグで回転、2本指ピンチで拡大縮小。TILTを有効にすると端末の傾きで球体が動きます。

      
タブ左の「動画 / ＋Shorts / Shorts」で、全タブ共通のShorts表示を切り替えます（初期は動画のみ）。「最新」タブの期間とNEWバッジの基準は ⚙設定 →「LATEST」で変更できます。

      
ジャンルは ⚙設定 →「GENRES」で自由に作成・名前変更・色変更でき、「自動でジャンル分け」で推定もできます。左の一覧（スマホは上部）にジャンルごとのセクターが並びます。

      
ノード（MATRIXではカード）をタップすると選択され、右（スマホは下）の情報欄が開きます。情報欄の「▶ 再生」を押すとダイブ演出つきで再生します。選択中のノードやカードをもう一度タップすると、演出なしですぐ再生します。

      
チャンネルを選ぶと上部に「全動画を取得」が出ます（APIキーが必要）。取得後は「全動画」タブとMATRIX表示で、月ごとに全件をスクロールして見られます。

      
MATRIX のカード下の M B C は MAGI の3人格の判定です。MELCHIOR＝再生数の統計、BALTHASAR＝未視聴で見やすい尺か、CASPER＝新着・ストック・その日の気分。3つ揃うと「全会一致」。

      
iPhone：Safariの共有ボタン →「ホーム画面に追加」でアプリのように全画面で使えます。
